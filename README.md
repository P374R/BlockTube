# Welcome to BlockTube! 

<a href="https://p374r.itch.io/blocktube"><img src="https://static.itch.io/images/badge-color.svg" width="150" alt="Available on itch.io"></a>

Jump into **BlockTube**, a 3D block-building sandbox game! Take control of your world as you freely explore, break and place blocks, build custom creations from scratch, and save or load multiple worlds anytime.

## Controls

- **Move:** `W`, `A`, `S`, `D`
- **Look Around:** `Mouse`
- **Jump:** `Spacebar`
- **Break / Place Block:** `Left Click` / `Right Click`
- **Pause & Save:** `Esc`
